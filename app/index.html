Flood Risk Methodology

Bowling Green, KY · Warren County · DEM-based rainfall model + FEMA NFHL

1. Terrain Data

The 3D terrain uses AWS Terrarium elevation tiles (global, 1–10m resolution) for the terrain mesh and vertical exaggeration rendering. The flood simulation uses a 5-meter KyFromAbove LiDAR DEM covering the full Bowling Green metro area.

2. Flood Elevation Slider

The water surface elevation slider (in feet MSL) sets a simulated flood stage. Areas where ground elevation is below this stage are shown in semi-transparent blue (RGBA: 0, 105, 148, 0.65). The elevation maps to a corresponding FEMA-approximate rainfall scenario:

4. Karst Sinkhole Depth

Sinkhole basins are color-coded by risk tier (derived from depression depth relative to surroundings). A 1-level early-flood boost is applied to cells in the top 20% by depression depth, reflecting that sinkholes have no surface drainage outlet.

5. Data Sources

  • DEM: KyFromAbove Phase 2 LiDAR, 5m resolution, EPSG:32616
  • Terrain tiles: AWS Terrarium (elevation-tiles-prod S3) — global, free
  • Parcels: Warren County PVA, 40,987 parcels
  • Buildings: OpenStreetMap via pyrosm, ~20,000 structures
  • FEMA: NFHL via ArcGIS REST API — Zone AE (100-yr), A (100-yr), X (500-yr)
  • Sinkholes: Derived from KyFromAbove DEM closed depressions
  • Roads: At-risk segments from flood_analysis.py
